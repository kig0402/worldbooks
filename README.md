# 📚 책틈 · 세계문학전집 (World Literature App)

민음사, 열린책들, 문학동네 등의 대한민국 대표 세계문학전집 명작들을 소개하는 모바일 최적화 데일리 큐레이션 웹 애플리케이션입니다.

- 🌐 **GitHub Pages 배포 주소**: [https://kig0402.github.io/worldbooks](https://kig0402.github.io/worldbooks)
- 🏛️ **참고 모델**: [데일리 스토아 철학 (Daily Stoic)](https://kig0402.github.io/dailystoic)의 세련된 100dvh One-Card 레이아웃과 일일 갱신 시스템 계승

---

## ✨ 핵심 기능 및 특징

- 📚 **대규모 도서 아카이브**: 민음사(150선), 열린책들(70선), 문학동네(60선) 등 엄선된 세계문학전집 총 280선 수록
- 📅 **매일 자정 자동 갱신**: 날짜 시드 난수 알고리즘(Mulberry32)을 통해 매일 7권의 새로운 도서 추천 (민음사 3권, 열린책들 2권, 문학동네 2권 균형 안배)
- 📖 **100% 검증된 실제 출판사 공식 표지**: 교보문고 공식 등록 ISBN 기반 실제 출판사 종이책 정본 표지 1:1 매칭
- 📝 **정갈한 정보 구성**: 책제목, 핵심 줄거리, 작품의 주제 및 문학적 의의, 독자 평점 및 리뷰 수, 대표 명문장, 오늘의 독서 화두 제공

### 4. 🧭 다채로운 필터 및 실시간 검색
- **큐레이션 필터 칩**:
  - ✨ 오늘의 7선 (매일 자정 자동 갱신)
  - 📚 전체 서재 (총 280선 아카이브)
  - 🏛️ 민음사 (150선)
  - 📖 열린책들 (70선)
  - 🌿 문학동네 (60선)
  - 🌟 성장/자아 · ⚖️ 실존/철학 · 🌹 사랑/관계 · 👁️ 사회/비판 등 주제별 필터
- **실시간 스마트 검색**: 책제목, 작가(헤세, 카뮈, 조지 오웰, 셰익스피어, 도스토옙스키 등), 출판사, 키워드를 입력하는 즉시 검색 및 바로가기

### 5. 📱 모바일 최적화 UX & 감성 인터랙션
- **100dvh 한 화면 원카드 뷰**: 불필요한 바깥 스크롤 없이 카드 내부만 부드럽게 스크롤되는 모바일 앱 핏
- **터치 제스처 & 키보드 탐색**: 스마트폰 화면을 좌우로 스와이프하거나, PC에서 `←`, `→` 방향키 및 `스페이스바`로 책장 넘기기 지원
- **3가지 감성 테마**:
  - 📜 *양장본 파피루스* (고전 책의 따뜻한 미색과 버건디/가죽 포인트)
  - 🌑 *미드나잇 다크* (깊은 밤의 흑요석 대리석 & 골드 포인트)
  - 🕊️ *새벽 슬레이트* (깔끔하고 지적인 모던 블루 & 슬레이트)
- **글자 크기 3단계 조절 (A±)**: 작게 / 보통 / 크게 가독성 최적화
- **책장 넘김 효과음 (🔔)**: 부드럽고 은은한 종소리/책장 넘김 사운드 (Web Audio API)
- **내 서재 보관함 (⭐ 북마크)**: 마음에 드는 책을 LocalStorage에 저장하여 모아보기
- **원클릭 공유 & 복사**: 명문장과 도서 소개를 깔끔하게 서식화하여 클립보드로 복사하거나 네이티브 공유

## 🚀 실행 및 깃허브 배포 가이드

- 100% 프론트엔드 단일 파일 세트(HTML/JS/CSS)로 빌드 과정 없이 즉시 실행됩니다.

### GitHub Pages (`https://kig0402.github.io/worldbooks`) 업데이트 방법
현재 폴더(`worldbooks`)의 모든 파일(`index.html`, `books.js`, `app.js`, `manifest.json`, `sw.js`, `icon*.*`)을 기존 `kig0402/worldbooks` 저장소에 덮어쓴 후 커밋 및 푸시하면 GitHub Pages에 즉시 반영됩니다.

```bash
cd /path/to/kig0402/worldbooks
# 또는 scratch/worldbooks 파일들을 해당 저장소에 복사한 후
git add .
git commit -m "feat: 실제 출판사 책표지, 데일리 큐레이션(매일 갱신), 스포없는 줄거리, 평점 및 상세 UX 개편"
git push origin main
```

## 📂 파일 구조
- `index.html`: 반응형 100dvh 모바일 프레임 레이아웃 및 테마 스타일, 모달
- `books.js`: 민음사, 열린책들, 문학동네 세계문학 36편의 정선된 데이터베이스
- `app.js`: 데일리 갱신 알고리즘, 필터링, 검색, 제스처, 사운드, 북마크 상태 관리 로직
- `manifest.json`: 모바일 홈 화면 추가를 위한 PWA 웹앱 매니페스트
- `sw.js`: 오프라인 캐싱 및 빠른 로딩을 위한 서비스 워커
- `icon.svg`, `icon-192.png`, `icon-512.png`: 고화질 앱 아이콘 세트
